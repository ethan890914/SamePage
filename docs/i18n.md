# Interface languages

The header language selector beside connection status switches between English
and Traditional Chinese (`zh-TW`). This preference is saved on the device as
`same-page.locale`; it does not change room settings or reset an active game.
Each player can choose their own interface language.

Edit `lib/i18n/zh-TW.ts` for Traditional Chinese translations. It contains typed
translations for the existing game copy, the site-wide interface dictionary,
and Chinese opening-word suggestions. Interface dictionary keys are English
source text; numbered placeholders such as `{0}` insert values without translating
player names, room codes, or game answers.

Converge accepts Chinese and English regardless of interface language. Chinese
words match by normalized spelling, without dictionary or meaning checks; simplified
and traditional spellings are not automatically treated as equivalent. English
inflection matching is preserved. Suggestions follow the local interface language.

Pattern Race always uses English letters, answers, and its English dictionary.
Only instructions, controls, and feedback are translated.

Run `node scripts/run-ts-smoke.mjs scripts/i18n-smoke.mjs` for word compatibility
checks and `npm run test:realtime` for Chinese private submission and reveal checks.
